О проекте

Этот сайт был создан в качестве финального проекта для закрепления навыков работы с семантическим HTML5.

Мои технические интересы

В процессе обучения я выделил для себя следующие ключевые направления:

  • Разработка пользовательских интерфейсов
  • Оптимизация производительности веб-страниц
  • Обеспечение доступности (A11y) для всех пользователей
  • Работа с современными графическими движками

Почему это важно?

Следование стандартам W3C гарантирует, что сайт будет одинаково хорошо отображаться в разных браузерах.
